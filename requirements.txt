# Windows System Media Transport Controls (SMTC) reader for the "Now Playing"
# source - reads the OS now-playing session via WinRT. Use the pywinrt split
# packages (prebuilt wheels incl. Python 3.13), NOT the monolithic `winsdk`
# package, which has no 3.13 wheel and compiles from source (huge, fails on
# low-RAM/low-disk machines). winrt-runtime is pulled in transitively.

winrt-Windows.Foundation; platform_system == "Windows"
# get_sessions() returns an IVectorView, which lives in the collections
# namespace - without this package iterating sessions raises ModuleNotFoundError.
