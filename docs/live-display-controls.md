# Live Display Controls

The buttons at the bottom of the main window give you instant, manual control of
the projected display during an event.

These controls are **temporary overrides**. They do **not** change your moods,
rules, player state, or background rotation — those keep running underneath.
Nothing here is saved: everything resets to inactive the next time Beam starts.

## Show Message / Clear Message

Opens a small dialog where you type a message and pick how long it stays on screen
(**5–60 seconds**, default 15). The message appears centered, in large white text,
on the preview, the projector, and the browser display. It disappears
automatically when the time runs out.

While a message is showing, the button becomes **Clear Message** so you can remove
it early.

A message still appears **on top of a blackout**, so you can black out the screen
and then show only a short message.

### Example messages

- `ÚLTIMA TANDA` (last tanda)
- `PERFORMANCE IN 5 MINUTES`
- `BREAK - BACK IN 10 MINUTES`
- `PLEASE CLEAR THE FLOOR`

## Display

Shows or hides the projector window.

## Blackout / Resume

**Blackout** instantly turns the projected display fully black. Your moods, rules,
and background rotation keep running in the background — only the output is hidden.
While blackout is active the button becomes **Resume**; press it to return to the
live display.

## Status bar display state

The bottom status bar summarizes the current state:

```
Player: Playing | Mood: Tango | Display: ON | Network: OFF
```

- **Player** — current playback status from your music player.
- **Mood** — the mood currently selected.
- **Display** — `ON` when the projector window is open, `OFF` when closed, or
  `BLACKOUT` while blackout is active.
- **Message** — shown only while a temporary message is active; counts down the
  seconds remaining, e.g. `Message: 12s`.
- **Network** — `ON` when the browser/tablet display is enabled, otherwise `OFF`.

## Good to know

These controls are about the **output only**. They do not stop the music, pause
the player, end a mood timer, or stop background rotation. When a message expires
or you press Resume, the normal live display returns exactly as it was.
