Beam-project

About

Beam is an open source, cross platform application used to gather and display information about the songs that are played using the most common music players running on PCs.

Playlist information is constantly gathered the the application can display the information of the previous, current or next songs.

Basically, Beam takes the ID3-tags that are specific to the music files. These tags contain details about the song like the Artist, Title, Album, etc.

The information provided by ID3-tags can optionally be modified/corrected in order to display the needed information.

With the use of custom rules (see below), Beam can filter and detect relevant information about the current playlist or current song and display this information as needed.

What's new in v0.9.3.0

  • Live display controls: Blackout and a temporary Show Message overlay, with a new segmented status bar.
  • Cut / Trim rule now works on any input tag, not only the title.
  • Mood backgrounds: Keep existing background plus a Readability blur/dim control for timed message moods; the mood editor Background section is now a single Background type dropdown.
  • Cover-art Advanced display options (corner radius, outline) now apply to the network / browser display too.
