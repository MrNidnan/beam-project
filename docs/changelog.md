## Recent highlights

A friendly summary of the most notable changes in this fork. See the full
changelog for every detail.

- **Played History (session setlists)** — auto-save the songs you played as text,
  CSV, and a best-effort M3U8 playlist (`Settings > Played History`).
- **Live display controls** — temporary **Show Message** (5–60s) and
  **Blackout / Resume**, with a smarter status bar.
- **Now Playing source** — follow almost any app via the OS media session (SMTC on
  Windows, MPRIS on Linux).
- **Smarter backgrounds** — keep-existing with a **Readability** blur/dim, color,
  single image, and slideshow modes, plus artist/orchestra overlays and cover art
  as background.
- **Better cover art** — preserves aspect ratio, with optional outline, rounded
  corners, feathering, and opacity, on both the desktop and browser displays.
- **More players** — Foobar2000 via Beefweb, VirtualDJ, AIMP (Windows), and fixes
  for MediaMonkey, JRiver, Mixxx, iTunes, Spotify, and Icecast.
- **Profiles** — separate named setups for different venues or nights.
- **Rules** — the **Cut / Trim** rule works on any tag, and hide conditions
  support tag / operator / value with comma-separated lists.
- **Auto-save** — no Save button; changes apply live and save on exit.
- **Log viewer** — `Help > Open Log Viewer`.
